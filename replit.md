# AI Interview System (Aegis Assessment)

An AI-powered technical interview platform that analyzes a candidate's resume and generates 5 personalized interview questions grounded in ML textbook knowledge from Pinecone.

## Run & Operate

- **Frontend** (`artifacts/interview-app: web`): React + Vite dev server at `/`
- **Backend** (`artifacts/api-server: API Server`): FastAPI uvicorn at `/api`
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- Required env: `PINECONE_API_KEY`, `PINECONE_HOST`, `OPENROUTER_API_KEY`

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- **Frontend**: React + Vite, Tailwind v4, shadcn/ui, TanStack Query
- **Backend**: FastAPI (Python 3.11), uvicorn, aiosqlite (SQLite)
- **AI/Vector**: Pinecone v9 for vector search, OpenRouter API (claude-3-haiku + text-embedding-3-small)
- **PDF parsing**: PyMuPDF (fitz)
- Validation: Zod (frontend), Pydantic (backend)
- API codegen: Orval (from OpenAPI spec)

## Where things live

- `backend/` — Python FastAPI backend (routes, services, models, database)
- `backend/main.py` — FastAPI app entrypoint
- `backend/routes/` — session.py (upload + session), interview.py (answers + summary)
- `backend/services/` — resume_parser.py, rag_service.py, question_generator.py, session_manager.py
- `backend/interview.db` — SQLite database (auto-created on first start)
- `artifacts/interview-app/src/` — React frontend (pages: Upload, Interview, Summary)
- `lib/api-spec/openapi.yaml` — API contract source of truth

## Architecture decisions

- FastAPI Python backend replaces the default Express scaffold; uvicorn runs from the workspace root using `--app-dir /home/runner/workspace`
- SQLite (aiosqlite) used instead of PostgreSQL — no external DB needed for interview sessions
- Pinecone v9 SDK uses lazy loading; import `Pinecone` from `pinecone._client` directly
- Resume text and skills sent to OpenRouter to generate embeddings for Pinecone vector search
- Questions generated by Claude-3-Haiku with a strict prompt ensuring textbook-grounded, personalized questions

## Product

3-page interview flow:
1. **Upload** — Drag-and-drop resume PDF + role selection → calls `/api/session/start`
2. **Interview** — One question at a time with progress bar → calls `/api/answer` per submission
3. **Summary** — Full Q&A session review with topics covered → calls `/api/summary/:id`

## Gotchas

- Pinecone v9: `from pinecone._client import Pinecone` (lazy loading makes top-level import fail)
- `pinecone-client` v6 is a stub that raises an error — use `pinecone` (v9+) instead
- Backend workflow command: `uvicorn backend.main:app --host 0.0.0.0 --port 8080 --reload --app-dir /home/runner/workspace`
- Tailwind v4: `dark` is a variant, not a utility — never use `@apply dark`
- Session start takes 10-30s (resume parse + embedding + Pinecone query + LLM generation)
